PRIORITY CHANGE
The most important priority is now the logged-in user experience around "Today’s Echo".

The app should not feel like a generic dashboard or a list of modules. When a user logs in, the main experience should immediately answer:

"What should I practice today?"

The user should think:

"I’ll do today’s practice."

Not:

"Which module should I open?"

Do not use Git, commits, branches, PRs, or deployment steps. Work directly in the current Replit project.

PRIMARY GOAL — Make Today’s Echo the center of the app

Redesign the logged-in homepage/dashboard so the first and most important thing a user sees is:

Today’s Echo

This should become the main entry point into practice.

The Today’s Echo card/section should feel custom, warm, and central to Murcielingo.

It should include:

- A clear title: "Today’s Echo"
- A short supportive sentence explaining what the user will practice today
- A primary CTA:
  - "Start today’s practice" if no session is active
  - "Resume today’s practice" if a session exists
- Current CEFR level

  - Pronunciation
  - Listening

  - Sentence building
  - Mixed review

- A soft Murcielingo-specific visual motif:
  - echo rings
  - sound wave
  - phrase bubble
  - subtle bat-wing curve
  - microphone pulse

Avoid generic icons and generic SaaS dashboard cards.

FREE VS PAID BEHAVIOR FOR TODAY’S ECHO

Today’s Echo should work for both free and paid users, but with different depth.

Free user:

- Can access a limited daily Today’s Echo session
- Should clearly understand what is free
- Should see a polished upgrade prompt after the free daily practice limit is reached
- Should not feel like the app is broken or empty

Paid user:

- Can access the full adaptive Today’s Echo session
- Should get richer mixed practice
- Should get adaptive review based on mistakes, saved words, pronunciation, and level

Admin user:

- Should still land in the normal learner dashboard unless they choose Admin
- Admin link should be available only if role is admin/administrator
- Admin should not replace Today’s Echo as the main product experience
