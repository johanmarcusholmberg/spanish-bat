GOAL
Today’s Echo should not only look like the main feature — it should behave like the main daily practice entry point.

The user should understand:
- what today’s practice is
- why it was chosen
- what happens when they start
- whether they are continuing, completed, or limited by free plan
- what they can do next

TASK 1 — Verify Today’s Echo CTA behavior

Audit what happens when the user clicks:

- Start today’s practice
- Resume today’s practice
- Review saved words
- Unlock full adaptive practice

Make sure each CTA leads somewhere real and useful.

If a final adaptive backend does not exist yet, route the user to the best existing practice flow and pass enough context so it feels like a Today’s Echo session.

Avoid dead buttons, placeholder screens, or generic routes.

TASK 2 — Add clear Today’s Echo states

Implement or verify these states:

1. Not started
- CTA: Start today’s practice
- Shows today’s focus, level, estimated time

2. In progress
- CTA: Resume today’s practice
- Shows progress, e.g. 3 of 8 completed

3. Completed
- CTA: Review saved words or Practice more
- Shows a short completion message

4. Free limit reached
- CTA: Unlock full adaptive practice
- Shows clear but friendly upgrade copy

5. No data yet
- CTA: Begin first practice
- Explains that Murcielingo adapts after the user starts practicing

6. Error/loading
- Loading should look intentional
- Error should be human-readable and offer retry or fallback

TASK 3 — Make Today’s Echo plan data structured

Avoid hardcoding everything directly inside JSX.

Create or refine a small Today’s Echo model/helper/hook such as:

- useTodaysEcho()
- buildTodaysEchoPlan()
- getTodaysEchoState()

The returned object should include:

- status
- title
- description
- focusArea
- level
- estimatedMinutes
- sessionType
- progressCurrent
- progressTotal
- primaryActionLabel
- primaryActionTarget
- secondaryActionLabel
- secondaryActionTarget
- isLimitedForFreeUser
- upgradeReason
- explanation

This can use existing user/practice data where available.

If real adaptive data is not available yet, use a clean temporary fallback and mark it clearly with a TODO.

TASK 4 — Add “why this today?”

Add a small expandable or subtle explanation near Today’s Echo:

“Why this today?”

“Based on your A1 level and recent vocabulary practice, today focuses on recall and pronunciation.”

This should be simple and human, not technical.

Avoid exposing raw scoring, subscription objects, or implementation details.

Paid users:

Admin users:
