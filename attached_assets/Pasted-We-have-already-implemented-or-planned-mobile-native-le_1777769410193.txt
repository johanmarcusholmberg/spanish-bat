3. Echo Memory
--------------------------------------------------

Create or refine the concept of “Echo Memory”.

Echo Memory should represent what Murciélingo remembers from the user’s practice history.

It should track or prepare for tracking:

- phrases the user struggled with
- slow answers
- skipped speaking items
- repeated mistakes
- recently improved phrases
- topics the user practices often

If the full backend structure already exists, connect to it.

If not, create a lightweight frontend/service-layer foundation that can later be backed by persistent storage.

Important:
- Do not overbuild this.
- Do not create a complex analytics dashboard.
- Do not expose lots of raw metrics to the user.

User-facing Echo Memory should appear as a compact section or small card, for example:

Title:
“Echo Memory”

Text examples:
- “Murciélingo is remembering the phrases you need to repeat.”
- “3 phrases are ready for review.”
- “You improved your recall on restaurant phrases.”

The purpose is to make the product feel personal and adaptive.

For free users:
- Show a limited Echo Memory preview.
- Example: “Echo Memory preview: Murciélingo can remember your weak phrases.”
- Paid upgrade hook: “Unlock full Echo Memory to keep adapting your sessions.”

For paid users:
- Show active Echo Memory details in simple language.
- Allow Echo Memory items to feed into Today’s Echo Practice.

--------------------------------------------------
5. Level readiness and continuing practice
--------------------------------------------------

When the system detects that the user has completed enough practice at a level, avoid the feeling that the app is “out of content”.

Instead, show a choice:

Title:
“You may be ready for a level check.”

Options:
1. “Take level check”
2. “Keep practising this level”

If a level check system exists, connect the first option to it.

If not, add a safe placeholder that clearly says:
“Level checks are coming soon.”

The second option should continue generating/recommending review or variation practice at the current level.

The app should never say:
“You have completed all practices.”

Use:
“You’re ready for a level check — or you can keep strengthening this level.”
