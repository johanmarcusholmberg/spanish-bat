GOAL 1 — Reduce generic icon usage drastically

- top navigation
- Today’s Echo
- Continue learning cards

What to do:
- use fewer icons overall
- remove icons where they are not necessary
- stop relying on one generic icon per feature as the primary identity
- create a more product-specific visual language

Introduce a small Murcielingo motif system using simple custom visuals, CSS/inline SVG patterns, or curated icon replacements inspired by:
- echo rings
- sound waves
- phrase bubbles
- microphone pulse
- path dots / progress route
- subtle wing-like curve shapes

Examples:

GOAL 2 — Redesign Today’s Echo so it feels like a session experience, not just a big card

Redesign it to feel more like Murcielingo’s core learning ritual.

Structure suggestion:
- small eyebrow label: Today’s Echo
- strong title
- short human explanation
- one clear session-focus row
- one clear meta row (level, time, session type)
- one strong CTA

  “Built from your level and recent practice”

  “A short Spanish session based on what you need to repeat next”

The section should feel:

- session-oriented
- more alive

Improve internal spacing and hierarchy so it feels designed, not auto-generated.
